# Proyecto Final - Alan Walker

## Descripción

Este proyecto consiste en la creación de un sitio web dedicado al DJ y productor musical Alan Walker.

El sitio contiene información sobre su biografía, álbumes, canciones, giras, fotografías y videos.

Fue realizado como proyecto final del curso de Desarrollo Web de CoderHouse.

## Tecnologías utilizadas

- HTML5
- CSS3
- Sass (SCSS)
- Bootstrap 5

## Páginas del sitio

- **Inicio:** biografía y trayectoria de Alan Walker.
- **Álbum:** canciones y música destacada.
- **Giras:** fechas y lugares de sus presentaciones.
- **Galería:** fotografías y videos.
- **Contacto:** formulario de contacto.

## Características

- Diseño adaptable a celulares, tablets y computadoras.
- Menú de navegación responsive.
- Estilos organizados mediante Sass.
- Uso de animaciones y transiciones.
- Carruseles de imágenes y videos.
